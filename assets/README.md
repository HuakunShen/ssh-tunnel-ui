# Brand assets

`logo.svg` is the source of truth: a tunnel portal (the bore), a ground line and
a light at the end, on the app's own dark tile (`#1d1f27` → `#0a0b0e`, accent
`#62cdff` → `#0a7dff`). Everything below is derived from it.

| File | Purpose |
|---|---|
| `logo.svg` | 1024×1024 master, used to generate the app icon |
| `logo-1024.png`, `logo-512.png` | raster masters for docs, READMEs and stores |
| `logo-32.png` | the tight-crop favicon mark at 32 px |
| `apps/web/static/favicon.svg` | favicon, same design with the mark scaled 1.18× and a full-bleed tile so it survives 16 px |
| `apps/web/static/favicon-{16,32}.png` | PNG fallbacks for engines that will not take an SVG tab icon |
| `apps/web/static/apple-touch-icon.png` | 180×180, opaque and square (iOS applies its own mask) |
| `apps/desktop/src-tauri/icons/` | generated by `tauri icon`, including `icon.icns` for the macOS bundle |

Regenerate the app icon after editing `logo.svg`:

```sh
cd apps/desktop && pnpm exec tauri icon ../../assets/logo.svg -o src-tauri/icons
```

The PNGs are rendered from the same SVG at an exact pixel size per file, so the
16 px favicon is a real 16 px raster rather than a downscale of a 1024 px one.
